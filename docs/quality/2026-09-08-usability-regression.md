## 验证方式

- 组件测试通过可见按钮、表单与 KeepAlive 切页验证，不直接调用组件内部方法。
- 本轮新增 14 项测试；保留原有测试，同步分区页面“预演后布局”的旧断言。
- 本地运行格式检查、lint、类型检查、全量前端测试、Web 生产构建和 Rust 格式检查。
- Rust 编译、Clippy、Rust 测试及 NSIS 安装包交由 GitHub Actions；不在本地生成安装包。
- 所有恢复/删除组件测试使用内存替身，未触碰真实隔离文件或磁盘分区。

## 验证边界

- 权限契约与原生调用单元测试不等于已安装程序的视觉验收；标题栏效果仍需在新安装包中检查。
- 分区写入仍受安全门禁约束；本轮未开启或执行分区合并、删除、格式化。
- 测试包未签名，不能承诺消除 SmartScreen 或杀毒软件的发布者警告。
- 不将最小化窗口的尺寸或后台截图解释为已经确认的窗口故障。
