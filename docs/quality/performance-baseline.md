# 性能与诊断基线

> 版本：1.0 · 日期：2026-08-17

## 固定基线

| 操作                |      目标 | 说明                                       |
| ------------------- | --------: | ------------------------------------------ |
| 首页磁盘发现        |  1,500 ms | 从命令进入到完成容量/卷发现                |
| 分区拓扑发现        |  5,000 ms | 固定 Windows Storage 查询与保守映射        |
| 清理预览扫描        | 30,000 ms | 首批固定规则；长目录扫描使用独立可取消任务 |
| Web 生产构建        |  2 分钟内 | 本地只构建前端，不生成安装包               |
| GitHub 缓存 Release |    数分钟 | 冷缓存单独记录，不作为稳定承诺             |

应用只记录固定操作名、耗时、阈值、是否通过和时间；不记录当前文件名、扫描路径或内容。最多保留当前进程 100 条并在设置页展示。

崩溃 Hook 不保存 panic 文本，因为第三方错误可能包含用户路径。磁盘文件最多保留 20 条固定字段。关闭诊断保留会立即清空现有崩溃标记并禁止后续写入。

## 回归门禁

- 每次提交运行 Vue/Rust 单元测试、lint、类型检查和生产 Web 构建。
- Release 在 GitHub Windows Runner 验证 Authenticode、安装/卸载、SHA-256 和来源证明。
- 性能阈值用于发现回归，不把单次慢设备结果描述成系统故障。
- 修改阈值必须附 Windows 版本、存储类型、冷/热缓存和样本数量，不得为让测试变绿而任意放宽。
